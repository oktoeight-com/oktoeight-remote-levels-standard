# Contributing

Propose changes through a GitHub issue or pull request.

A proposal must identify the affected level, the operational problem, and evidence from a real use case or recognized reference. State whether the change affects control authority, field presence, fallback behavior, or the boundary between two levels.

Keep the model domain-neutral. Put industry-specific controls in examples or mappings unless they are necessary for every industrial system at that level.

When a change affects the standard, update the human-readable README, the Agent Skill, any worked example, and the changelog together. Keep the definitions, classification procedure, required inputs, and output record synchronized across the README and skill.
